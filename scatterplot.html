How To Read

如何解讀這張 GitHub 散佈圖？

這一頁把 stars 與 forks 放在同一張圖上，幫你快速辨認高人氣專案、技術採用型專案，或值得比較的 repo 群。 它適合用來補足排行榜看不到的分布感，也能幫你更快決定哪些專案值得深入閱讀。

01 看人氣與採用差異

有些 repo stars 很高但 forks 較低，有些則代表被更多人實際延伸或參與，兩者意義不同。

02 找異常亮點

散點位置特別突出的專案，常常就是你值得點開、比較或加入追蹤名單的候選。

03 搭配其他視圖判斷

如果你在這裡看到有趣的 repo，再搭配關聯圖與首頁搜尋，會更容易判斷它的上下文與替代方案。
