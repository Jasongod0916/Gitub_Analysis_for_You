關於我們

GitHub 上的資訊很多，但真正麻煩的通常不是找不到專案，而是不知道下一步該點哪裡、哪些值得花時間看。 這個網站就是為了把那段判斷成本降下來。我們想把「找專案」這件事，從一串搜尋結果，變成一條更有方向感的探索路徑。 你不只會看到熱門 repo，還能更快知道它和哪些 topic、language、相關專案連在一起。

Features

我們提供哪些功能

這個網站不是只列出 repo，而是把搜尋、排名與視覺化串起來，幫你更快判斷下一步要看哪裡。

01 關聯圖

把 repo、topic、language 的關係視覺化，讓你從一個專案延伸找到相似技術脈絡。

02 排行榜

整理 repository owner 貢獻排行與程式語言分布，快速看出目前收錄專案的整體組成。

03 散佈圖

用視覺化角度觀察專案之間的分布與差異，未來可以更快找出值得比較的群組。
